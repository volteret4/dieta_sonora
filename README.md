# dieta_sonora
Creamos dos proyectos:
- CSV Lanzamientos: para ver que discos de nuestros artistas tenemos pendientes comprar
- Web Estadisticas: Controlar cuanto tiempo pasa desde que sale el disco, se compra y se escucha.

## Lanzamientos
A diario se actualizará usando `revisor_calendario.py` añadiendo los eventos en el calendario para ese dia a los preexistentes en el albums.csv


## Estadisticas
Gracias a otro proyecto guardo en mi calendario `radicale` como eventos de día entero el lanzamiento de cada artista.
Este mismo crea una tarea en otro calendario `radicale` con DTSTART el momento en que compro el disco y también se encarga de añadir la fecha de completado una vez escuchado.
